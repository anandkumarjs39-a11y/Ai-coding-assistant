System Architecture (Client-Server Model)

This application implements a decoupled, modern multi-tier architecture where the frontend client interfaces with a lightweight Python Flask REST API backend over asynchronous HTTP/JSON.

  • Presentation Layer: Modular HTML5, CSS3, ES6+ JavaScript with Bootstrap 5 and embedded Monaco Editor (VS Code engine).
  • Application & API Layer: Python Flask microservices handling route dispatching, token verification, and input validation.
  • Security Boundary: Zero AI provider API keys or database credentials exist on the client; all processing is secured server-side.
